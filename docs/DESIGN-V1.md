# DSH TUI / Fieldnotes — 第一版设计说明

## 目标与基调

把终端做成能长时间工作的桌面：主区域用来理解任务进展，细节在需要时出现。设计基调是安静、可读、可检查。Fieldnotes 表示工作记录，不改变 DSH 的 Agent 身份或能力。

用户授权本轮由主设计师决定第一版，交付后再按偏好调整。这轮保留实现、固定输入、视觉输出、基线提交与验证记录，作为 benchmark 素材。

## 信息架构

第一层是工作本身：人的输入、Agent 回复、工具动作。人的消息使用青绿纵线；工具使用低对比度纵线与简短预览；正文保持终端背景。工具失败同时具有文字和颜色信号。

第二层是当前状态：输入区上方显示工作步骤和待处理消息，底栏显示模型、上下文用量、工作目录与权限。大窗口保留细节，小窗口优先保留影响决策的容量和权限。

第三层是工作台：Ctrl+K 打开按任务命名的入口，上下文、工具全文、队列与 Agent 目录无需常驻屏幕。在 48 列窗口中仍保留完整编辑空间。

## 视觉规则

| 元素 | 第一版选择 | 原因 |
|---|---|---|
| 强调色 | `#88c8bc` 青绿 | 统一身份、当前动作与导航 |
| 正文 | 终端默认前景；用户文字 `#e4e4dc` | 尊重终端字体与阅读习惯 |
| 次要文字 | `#9aa8aa` | 来源与说明保持可读 |
| 辅助文字 | `#718184` | 快捷键降低视觉权重 |
| 状态 | 鼠尾草绿 / 柔红 / 琥珀 | 配合文字，避免只靠颜色表达 |
| 分组 | 留白与纵线 | 缩减重复边框和大面积底色 |
| 输入区 | 轻量标题、原生编辑器、一条底线 | 保留成熟的输入与 IME 实现 |
| 弹窗 | 暗面板、搜索、明确返回键 | 深入查看后返回草稿 |

终端无法由应用任意设置字体、字号和行距。HTML 对照页使用本地等宽字体模拟字符网格，不把网页排版能力当成 TUI 功能。

## 原生能力如何成为交互

| 用户意图 | TUI | DSH 依据 |
|---|---|---|
| 开始下一件事 | Enter | `Agent.followup` |
| 修改当前方向 | `/steer` | `Agent.steer` |
| 补材料，暂不开始 | `/inject` | `Agent.inject` |
| 查看待处理输入 | `/queue` | `inbox.nextTurn / nextStep` |
| 撤回输入 | 队列中选择撤回 | `inbox.remove(id)` |
| 确认模型看到了什么 | `/context` | `session.deriveMessages()` |
| 确认工具能力 | `/tools` | `header.tools`；请求前为 scoped `tools.schemas` |
| 检查具体行动 | `/inspect` | `tool/call` 与配对 `tool/result` |
| 了解协作情况 | `/agents` | `subagents.listChildren(parentId)` 与 live status |
| 引用文件 | `@` 补全 | `fileReferences` 与共享引号语法 |
| 审查计划、回答问题 | 全文 → 决策 / 多选 / 自定义 | `user-questions/request` 的 intent 与 options |

上下文可能包含系统 prompt、工作区约束、能力目录、运行时快照、模型输出与工具结果。第一版保留来源，用中文标注语义；全文与聊天记录分开。

尚未处理的 `/inject` 材料只出现在 `/queue`，不提前宣布模型已收到。压缩后用户历史保留，当前上下文通过内核派生读取。工具目录注明最近请求或当前作用域，避免把待组装能力说成已经发给模型。

## 工程取舍

- 保留终端原生 scrollback，折叠内容通过全文面板补全。
- 不增加常驻侧栏，窄终端也能编辑和阅读完整句子。
- 发布 `dshTui` 服务；注册撤销按所有权处理，乱序卸载不污染其他插件。
- 区分消息变化、视觉配置变化和普通状态变化，避免 token 或状态通知清空历史缓存。
- 原生操作由内核执行。面板不自行生成工具调用、派生 Agent 或重跑 prompt assembly。
- 评估与实现由本轮主代理完成，没有使用子代理。

## 验证与 benchmark

固定虚构输入在 `scripts/fixtures.mjs`。`scripts/design-preview.mjs` 从 Git HEAD 读取基线，使用同样事件和宽度调用实际组件 `render(width)`，不手工仿画界面。

本轮基线 `9f778a0797bad8b9a0f4ef605b96b3e9f3ba3358`，不含用户开始本轮前尚未提交的模型路由修改。对照在 [benchmark-v1/index.html](benchmark-v1/index.html)。

- 同一会话：37 行 → 30 行；48 列和 100 列输出均未越界。
- 1,000 条历史、20 次刷新：重复渲染历史行 20,000 次 → 0 次。这不是总体速度提升倍数；仍有 O(消息数) 帧拼接。
- 真实 PTY 演示：工作台、上下文选择、全文、Esc 返回与 Ctrl+C 退出。
- 隔离 DSH_HOME 的真实运行时：standard 预设、26 个工具、无模型请求的 inject、队列查看和撤回。
- 测试覆盖缓存调用链、容量异步竞态、窄窗、replacement、独立取消、草稿保留、多选、计划审阅、原生输入方式和文件引号。

真实模型推理、远程 SSH、跨平台终端与多 Agent 满负载未做全面测量，不包含在本轮性能结论中。

## 下一轮可按偏好调整

1. **密度**：进一步紧凑，或增加消息间距。
2. **工具预览**：目前最多 7 行，可改为只显示标题或更多细节。
3. **思考**：默认折叠，可调整默认可见性。
4. **品牌**：小型 DSH 字标，可恢复鲸鱼作为可选启动页。
5. **颜色**：青绿可换为蓝、暖灰或终端原色。
6. **协作布局**：根据实际使用决定是否需要固定 Agent 区域。
